
# 🧹 CleanData AI

An Interactive Platform for Automated Data Cleaning and Visualization.

CleanData AI is a Streamlit-based application designed to simplify data preprocessing and exploratory data analysis (EDA). The platform enables users to upload datasets, clean data automatically, visualize insights, and export processed datasets with ease.

---

## 🚀 Features

### 📂 Dataset Upload
- Supports CSV and Excel files (.csv, .xlsx, .xls)

### 🧹 Data Cleaning
- Handle missing values
- Remove duplicate records
- Rename columns
- Delete unnecessary columns
- Fix data types
- Text cleaning operations
- Categorical encoding

### 📊 Data Analysis
- Dataset overview
- Data quality analysis
- Summary statistics
- Outlier detection

### 📈 Visualization
- Histograms
- Bar Charts
- Scatter Plots
- Correlation Heatmaps
- Interactive Plotly Charts

### 🤖 AI-Based Suggestions
- Intelligent recommendations for improving dataset quality
- Automated data cleaning guidance

### 📥 Export
- Download cleaned datasets in CSV format
